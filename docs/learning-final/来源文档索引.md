# 最终学习文档来源索引

本索引把原 `docs/` 与 `study-notes/` 下的 Markdown 归档到最终学习目录，并说明每类文档在最终版中的处理方式。所有原始文件都保留在 `原始资料/` 对应子目录。

## 来源分类

| 原始目录 | 主要内容 | 最终版处理 |
|---|---|---|
| `docs/course` | 0～17 章、附录、作业、面试 | 作为主教材主干，按依赖重新排序 |
| `docs/deep-learning` | 项目总览、架构、依赖、逐文件、异常 | 独有语义作为工程补充，索引集中反查 |
| `docs/deep-dive` | 入口、工具、会话、协作、测试专题 | 独有源码链路合并到工程补充 |
| `study-notes` | Java 21、启动流程、对话模型、优化 | 作为历史视角和实现补充 |
| `study-notes/sourcebook` | sourcebook、源码精读、覆盖清单 | 方法证据/文件覆盖单独归档 |
| 根目录与 `docs` 配置文档 | README、Maven、项目指南 | 合并到构建/部署/项目定位部分 |
| `docs/learning-integrated`、`docs/final-learning`、`docs/JIMICODE-整合学习教材.md` | 之前生成的整合版 | 归档到 `原始资料/历史整合版/`，不作为新的主线入口 |

## 归档内容

`原始资料/course/` 保留课程主线原文；`原始资料/deep-dive/` 保留专题深潜；`原始资料/deep-learning/` 保留逐文件和逐方法教材；`原始资料/study-notes/` 同时收纳原 `study-notes` 顶层文件和 `sourcebook` 文件；`原始资料/根目录与配置/` 收纳项目 README、学习指南和构建指南。

## 如何回溯一段内容

主教材正文会在章节标题处说明主干来源；工程补充会写明补充来源；源码覆盖部分列出索引入口。需要核对完整原文时，按本表的归档分类打开 `原始资料/`，不要在根目录的多个旧入口之间反复跳转。

## 重复处理说明

重复判断按段落块进行：规范化连续空白和 Markdown 标题后完全一致的段落，在最终主教材中只保留一次；同主题但新增源码路径、调用链、实验步骤、错误处理或安全边界的段落继续保留。导航、版权、统一免责声明等结构噪声由最终版统一写出，避免每章重复。

## 维护规则

以后新增教材时，先更新主教材对应主题，再把新来源复制到 `原始资料/` 并在本索引登记。不要再创建平行的“总览/最终版/整合版”文件；如果内容属于源码证据，应放入源码反查章节；如果内容属于新能力，才新增章节。
