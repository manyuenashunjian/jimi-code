## 文件级通用审查表

对每一个生产文件都问：谁创建它？谁持有它？它是否线程安全？输入来自用户、模型、配置还是内部状态？路径和命令是否经过规范化？JSON/Markdown 是否可被 prompt injection？外部调用是否有 timeout？InterruptedException 是否恢复中断标志？IOException 是否应该 best effort？错误是给用户、模型、日志还是 session？对每个测试文件都问：它保护的是哪种回归？有没有把时间、随机、网络、home、真实 Git 或真实 provider 误带入？

## 覆盖率核对

这份索引覆盖 src 下所有扩展名为 .java 的文件，并且 00-源码逐文件覆盖矩阵提供同一批文件的包级职责视图。01-08 分册负责跨文件链路解释：入口/Agent、LLM、工具安全、持久化、协作/TUI、架构、构建调试和测试。三种资料分别回答“文件在哪里”“文件如何协作”“如何验证和排障”，不能用其中一类替代另外两类。
