# jimi-code · 依赖覆盖清单

## 当前事实

根项目 `pom.xml` 使用 Java 21、Maven、tui4j、Mordant、MCP SDK、Anthropic Java SDK、OpenAI Java SDK、SnakeYAML、Jackson、SLF4J 和 JUnit。原 Gradle 实现已经从当前仓库移除；`java-maven` 是另行复制到工作区根目录的独立 Maven 变体。

| 依赖 | 作用 | 真实调用入口 |
|---|---|---|
| tui4j | Java 终端 UI 事件循环 | `MewCode.main`、`MewCodeModel` |
| Mordant | Markdown/终端样式 | `MarkdownRenderer`、UI |
| MCP SDK | stdio/HTTP MCP Server 连接和工具发现 | `McpManager` |
| anthropic-java | Anthropic Messages 流式调用 | `AnthropicClient` |
| openai-java | OpenAI Responses 流式调用 | `OpenAiClient` |
| SnakeYAML | `.mewcode/config.yaml` 绑定 | `ConfigLoader` |
| Jackson | JSON、会话、工具参数和文件历史 | conversation/toolresult/filehistory |
| JUnit 5 | Java 单元测试 | `src/test/java` |

## 阅读要求

依赖表只记录项目实际使用点，不把 Maven/Gradle 的完整传递树冒充源码调用。阅读第三方库时先从构造器、Builder、回调和异常类型进入；若 source jar 不可用，标记 `source-unavailable`，只写已确认的 API 行为。
