# 07 源码文件与依赖索引

## 核心 Java 文件

入口与 UI：`MewCode.java`、`MewCodeModel.java`、`AppState.java`、`ChatMessage.java`、`MarkdownRenderer.java`。

Agent：`Agent.java`、`AgentEvent.java`、`StreamingExecutor.java`、`SubAgentTaskManager.java`、`AgentTool.java`。

配置：`AppConfig.java`、`ProviderConfig.java`、`McpServerConfig.java`、`HookConfig.java`、`ConfigLoader.java`。

LLM：`LlmClient.java`、`AnthropicClient.java`、`OpenAiClient.java`、`OpenAiCompatClient.java`、`ModelResolver.java`、`LlmException.java`、`StreamEvent.java`。

工具和安全：`Tool.java`、`ToolRegistry.java`、`ToolResult.java`、`PermissionChecker.java`、`PermissionMode.java`、各种 read/write/bash/git 工具。

状态和恢复：`ConversationManager.java`、`SessionManager.java`、`HistoryStore.java`、`ContextCompactor.java`、`RecoveryState.java`、`FileHistory.java`、`WorktreeManager.java`。

## Go 对照

对照阅读 `internal/agent`、`internal/llm`、`internal/tools`、`internal/permissions`、`internal/compact`、`internal/conversation`、`internal/session`、`internal/worktree`、`internal/mcp` 和 `internal/tui`。Go 测试用 `go test ./...`，Java 测试用 Gradle 或 Maven；不要把一个实现的测试结果代替另一个实现的证据。
